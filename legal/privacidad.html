2. Qué datos tratamos

La versión inicial de Mi Bolsillo es una web estática y no incorpora cuentas de usuario, comentarios, base de datos ni formularios que envíen datos a un servidor propio. Si nos escribes por correo electrónico, trataremos la dirección y el contenido que incluyas para gestionar y responder la consulta.

La versión actual utiliza un tema oscuro fijo. El código JavaScript de Mi Bolsillo no utiliza cookies, localStorage ni sessionStorage para guardar preferencias o identificar a las personas visitantes. El proveedor de alojamiento puede tratar datos técnicos de acceso y seguridad conforme a sus propias condiciones.

La página de contacto incluye un enlace a incidencias de GitHub. Si lo utilizas, saldrás de Mi Bolsillo y la información que publiques allí será visible públicamente en el repositorio y quedará sujeta a las condiciones y política de privacidad de GitHub. No publiques información personal, bancaria ni financiera.

El proveedor de alojamiento, GitHub Pages, puede tratar datos técnicos necesarios para prestar, proteger y mantener el servicio. Consulta la política de privacidad de GitHub en GitHub Privacy Statement.

3. Finalidades y bases jurídicas

  • Responder a mensajes que nos envíes: gestión de tu solicitud y, según el caso, medidas precontractuales o interés legítimo.
  • Proteger y mantener la disponibilidad del sitio: interés legítimo y obligaciones aplicables del proveedor de alojamiento.
  • Newsletter, analítica o publicidad: no activar hasta describir aquí el proveedor, finalidad, datos, base jurídica y mecanismo de consentimiento aplicable.

4. Destinatarios y proveedores

El sitio está alojado mediante GitHub Pages. No se ha integrado en esta versión un proveedor de newsletter, analítica ni publicidad. Cuando se añadan servicios externos, se actualizará esta sección identificando al proveedor, su función y, cuando corresponda, las transferencias internacionales y garantías aplicables.

5. Conservación

Los correos se conservarán durante el tiempo necesario para atender la consulta y, después, durante los plazos necesarios para atender posibles responsabilidades. Debes concretar internamente un plazo o criterio de conservación y aplicarlo de forma coherente.

6. Derechos de las personas

Puedes solicitar el acceso, rectificación, supresión, oposición, limitación del tratamiento y portabilidad cuando proceda, así como retirar un consentimiento previamente otorgado. Escribe a mibolsillo@gmai.com e indica el derecho que deseas ejercer. Puede ser necesario verificar tu identidad de forma proporcionada.

También puedes presentar una reclamación ante la Agencia Española de Protección de Datos (AEPD).

7. Menores

Este sitio está dirigido al público general y no pretende recoger deliberadamente datos personales de menores. Si consideras que un menor nos ha enviado datos, contacta con el responsable para solicitar su revisión.

8. Seguridad

Aplicamos medidas razonables para mantener el sitio y los procesos de comunicación bajo control. Ningún sistema conectado a Internet puede garantizar seguridad absoluta.

9. Cambios en esta política

Esta política se revisará cuando cambien las funcionalidades, los proveedores o las obligaciones legales. La fecha de actualización aparecerá al principio de la página.
