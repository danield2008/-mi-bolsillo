Ayúdanos a mejorar Mi Bolsillo.

Puedes comunicar errores de contenido, sugerir temas o proponer mejoras para las herramientas.

Correcciones y sugerencias editoriales

Como canal provisional para incidencias públicas del sitio, puedes abrir una incidencia en el repositorio de Mi Bolsillo.

Abrir incidencia en GitHub →

Las incidencias de GitHub son públicas. Utiliza este canal solo para correcciones generales del sitio o del contenido.

Qué incluir en una corrección

  • La URL del artículo o herramienta.
  • Una explicación breve del posible error.
  • La fuente oficial o documento que permita comprobarlo, si lo tienes.

Qué no debes enviar

No publiques contraseñas, números completos de tarjetas, documentos de identidad, datos fiscales, información bancaria ni detalles de tu situación económica personal. Este sitio no ofrece asesoramiento financiero individual.

Contacto privado

La dirección de correo de contacto general se añadirá cuando se configure una cuenta específica para Mi Bolsillo. Mientras tanto, no se habilita un formulario que recoja datos personales sin un sistema de recepción y gestión adecuado.

Privacidad

Consulta la Política de privacidad y el Aviso legal. Esos documentos deben completarse con la identidad y datos de contacto del responsable antes del lanzamiento comercial o de solicitar monetización.
